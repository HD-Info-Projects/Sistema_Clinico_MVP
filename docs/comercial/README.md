## Sobre esta documentação

Todo o conteúdo foi produzido com base na análise do código-fonte do
repositório `Sistema_Clinico_MVP` (backend Flask e frontend Nuxt).

Nenhuma funcionalidade foi inventada: cada módulo descrito possui
correspondência em rotas, serviços, modelos, páginas ou componentes do
projeto. Itens encontrados em estrutura, mas sem implementação completa,
foram classificados como **Parcial**, **Em desenvolvimento** ou **Planejado**
nos documentos em que aparecem.

Nenhum dado sensível (senhas, tokens, credenciais, strings de conexão) foi
reproduzido nesta documentação.
